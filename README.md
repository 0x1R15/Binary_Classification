# Binary Classification using SVM
This project demonstrates the implementation of a Support Vector Machine (SVM) for binary classification. It includes data preprocessing, model training, prediction, and performance evaluation.

## Features
- Data preprocessing
- SVM model training
- Binary classification prediction
- Model evaluation using accuracy metrics

## Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib 

## Learning Outcome
Learnt to implement and evaluate Support Vector Machine (SVM) models for binary classification problems.
